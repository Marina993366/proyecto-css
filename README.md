# CSS Headers Collection – Pure CSS Practice

Este proyecto consiste en una colección de **headers (hero sections)** desarrollados como práctica intensiva de **CSS puro**, basados en distintos diseños visuales.

El objetivo principal fue reproducir layouts complejos utilizando únicamente **HTML semántico + CSS**, sin frameworks ni librerías externas de UI.

---

## 🎯 Objetivos del proyecto

- Practicar **maquetación avanzada en CSS**
- Trabajar con:
  - Flexbox
  - CSS Grid
  - Positioning (relative / absolute)
  - Z-index y stacking context
  - Gradientes y backgrounds complejos
  - Superposición de elementos
- Implementar un **mini design system** con variables CSS
- Mantener un código **ordenado, escalable y reutilizable**

---

## 🛠️ Tecnologías utilizadas

- **HTML5 semántico**
- **CSS3 puro**
- Google Fonts
- Variables CSS (`:root`)
- Sin frameworks (no Bootstrap, no Tailwind, no Sass)

---

## Cada header tiene:

- Sus propias imágenes

- Estilos encapsulados mediante una clase raíz (.businessAgency, .portfolio, .forum, etc.)

---

## 🎨 Mini Design System

**El proyecto incluye un mini design system implementado con variables CSS:**

- Tipografías

- Colores

- Presets de texto (font shorthand)
